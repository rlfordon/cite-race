# Design decisions (as of 2026-10-08)

## Mechanic
- The opinion is the board. You read the case and click a citation in its text (backward hop) or an entry in its citing-references list (forward hop). Clicking loads that opinion; you read it and filter its citing references by court, year and word.
- Score is hops, with time as tiebreaker. Par is the shortest path, shown after finishing.
- Jev races on the same puzzle. Its path shows alongside yours.
- Hints: headnote-style topic reveals for the target; Jev warmer/colder as a pairwise judgment.
- Local-only (hubs off) mode is a teaching mode, not needed for difficulty: in the SCOTUS graph, removing the top 100 hubs barely changes path length (CAP data, mean ~4 hops).

## Modes
- Any direction (default): each hop may go back (citation in text) or forward (cited-by list).
- One direction only (harder): back-only or forward-only. Pairs drawn from directed reachability. The ladder becomes a monotone staircase, which is the visual cue that the mode is on.

## Trail display: the chronology ladder (chosen)
- Sidebar, pinned. Time across (1789 to 2026), one row per hop going down. Blue pen line steps left for backward hops, right for forward hops. No "back/forward" words on the segments; the slope says it.
- Target year drawn as a dashed vertical line the full height, so the ladder doubles as a compass.
- Jev in red dashes on the same rows. No labels for Jev's cases; the name shows on hover only.
- Simultaneous turns: Jev's hop for a row is revealed only once you have made yours, so the red trail never runs ahead of the blue.
- Click an earlier row to return there and branch.
- Rejected: shelf of reporter volumes (volume axis), click-order running-head strip, table of authorities (keep for the end-of-game record only).

## Look
- Photocopied reporter page: white paper, black toner, two columns, running head, cite line, caption block. Type: Old Standard TT. No accent colour anywhere; the only colour is the two pens (player blue #1f3fbf, Jev red #c8201c).
- Citations in text: dotted underline at rest, pen underline once taken.
- The night-lights map (citation-highways.html) is for the start screen and the end-of-game replay, not for play.
- Parked: roadtrip / classic highway map direction (see ideas.md).

## Starters (2026-10-09)
- Curated famous-case puzzles in `data/prototype/starters.json`, generated by `scripts/make_starters.py` from the canon list in `scripts/starters.py`. Three groups: warm-ups (one citation apart), starters (two hops), three hops. The start screen lists them per mode; random draws remain for par 5 to 7.
- Par = shortest + 2 everywhere, except one-hop warm-ups, which are par 1.
- Finding from the graph: nearly every pair of famous cases is two hops apart, so difficulty comes from random pairs, not famous ones.

## Publishing
- static.case.law serves per-case HTML and JSON with open CORS, so a GitHub Pages build is feasible: ship the graph as compressed JSON, do BFS and puzzles in the browser, fetch opinion text per hop from the archive. Only real Jev would need a small proxy for the API key.

## Phones (2026-10-09)
- Under 820px the opinion comes first and scrolls as one column (no reporter pages). A bar pinned to the top carries hop, par, clock and the target (tap for the target dialog), then Trail, Cites, Cited by and Find. Trail and the citator open as bottom sheets over the opinion, so the reader keeps their place; Find takes the button row's place until Done. The sidebar and the citator are moved into the sheets by script when the screen narrows, and back when it widens. Mockup: `mockups/phone-sheets.html`.
- The trail sheet writes out Jev's latest case, since a phone cannot hover the red dots.
- On touch screens (`hover: none`) a tap on a citation or list entry opens a preview with the same brief summary as the desktop hover card; "Go to this case" commits the hop. On a phone the preview opens inside the citator sheet with a way back to the list. Cases already on your trail hop straight away. This costs a tap per hop but makes a mis-tap free, which matters in a game scored on hops.
- Desktop is unchanged.
- Jev is TypeSafe's typed-judgment model (see rlfordon/could-jev), run offline and saved: `scripts/precompute_jev.py` writes `docs/data/jev.json`, and the game replays it, so the live site needs no key or proxy. At each hop Jev reads the target's syllabus beside each case it could move to and answers one Score, "how closely related are the legal issues" (0 to 4); code takes the warmest. Code enforces the rules: the mode's direction, no revisits, the target taken when one hop away, a step back at a dead end, give up after 12 hops. Random draws come from a fixed pool of pairs Jev has raced (20 per mode by default), since a route can only be replayed if it was run. Jev's answers and the case summaries are cached in `data/jev/`, so reruns only ask new questions.
